# Project Prompt: Simple IoT World – MQ-2 Air Quality Monitoring System

Create a complete **IoT-based Gas, Smoke and Air Quality Monitoring System** named:

**“Simple IoT World – Air Quality Monitoring System”**

The project must use only an **ESP8266 NodeMCU CP2102** and a **4-pin MQ-2 Gas/Smoke Sensor Module** for environmental sensing.

The MQ-2 sensor has exactly four pins:

* **A0 – Analog Output**
* **D0 – Digital Output**
* **VCC – Power**
* **GND – Ground**

Do **not** use DHT11 or any temperature/humidity sensor.

## 2. Hardware Connections

### MQ-2 Sensor

Connect the 4 pins as follows:

| MQ-2 Pin | ESP8266 Pin |
| -------- | ----------- |
| **VCC**  | VIN / 5V    |
| **GND**  | GND         |
| **A0**   | A0          |
| **D0**   | D6 / GPIO12 |

### Important MQ-2 Function

* **A0:** Read the variable analog gas/smoke sensor value.
* **D0:** Detect whether the gas/smoke level has crossed the threshold.
* The threshold for D0 can be adjusted using the potentiometer present on the MQ-2 module.

**Important:** The MQ-2 is primarily a gas/smoke sensor. Do not claim that its raw analog value is a certified AQI measurement.

Also, because the MQ-2 module is powered from 5V and its analog output may be higher than the safe ADC input of some ESP8266 NodeMCU boards, use an appropriate **voltage divider/level protection on A0** according to the exact board specification.

---

## 3. LCD Connection

Use a 16×2 I2C LCD.

| LCD Pin | ESP8266    |
| ------- | ---------- |
| VCC     | VIN / 5V   |
| GND     | GND        |
| SDA     | D2 / GPIO4 |
| SCL     | D1 / GPIO5 |

Use I2C address:

**0x27**

If the actual LCD module uses a different I2C address, allow it to be changed easily in the code.

---

## 4. LED Connection

Connect:

```text
ESP8266 D3
    ↓
220Ω Resistor
    ↓
LED Anode (+)

LED Cathode (−)
    ↓
GND
```

The LED should indicate the gas/smoke warning status.

---

## 5. Buzzer Connection

```text
ESP8266 D4 → Buzzer (+)
ESP8266 GND → Buzzer (−)
```

The buzzer should turn ON when dangerous gas/smoke levels are detected.

# 10. Air Quality Status

For project/demo purposes, classify the MQ-2 analog reading as:

```text
0–100       → GOOD
101–200     → MODERATE
201–300     → POOR
301+        → VERY POOR
```

Display the corresponding status clearly.

Example:

```text
Gas/Smoke Value: 245
Status: POOR
```

**Important:** These are only demo thresholds for this project and are **not certified AQI values**. MQ-2 readings depend on sensor characteristics, warm-up, calibration, gas type, and environment.

# 19. ESP8266 Data Communication

The ESP8266 should:

1. Connect to Wi-Fi.
2. Read MQ-2 A0 analog value.
3. Read MQ-2 D0 digital value.
4. Determine the gas/smoke status.
5. Control LED.
6. Control buzzer.
7. Send sensor data to the Node.js server.
8. Fetch LCD text from the server.
9. Fetch LED control commands.
10. Repeat every **10 seconds**.

Use HTTP communication between ESP8266 and the Node.js/Express server.
